# Accessibility — WCAG 2.1 AA

## HTML Semantics

- Use landmarks: header, main, footer, nav, aside, section
- Single <main> per page
- Strict heading hierarchy (h1 → h2 → h3, no skipping)
- Use <article> for self-contained content blocks

## ARIA

- Prefer native HTML over ARIA (button over div[role="button"])
- aria-label for elements without visible text
- aria-live="polite" for dynamic content updates
- aria-describedby for additional context

## Keyboard

- All interactive elements reachable via Tab
- :focus-visible for focus styles (not :focus alone)
- Never tabindex > 0
- Escape key closes modals/popups

## Color & Contrast

- 4.5:1 minimum for normal text, 3:1 for large text
- Never convey information by color alone
- Test with forced-colors media query

## Images & Media

- Meaningful alt text (or alt="" for decorative)
- Always set width/height attributes (prevents CLS)
- Captions for video, transcripts for audio

## Forms

- Every input linked to a label (for/id or nesting)
- Error messages linked with aria-describedby
- Required fields marked with aria-required
