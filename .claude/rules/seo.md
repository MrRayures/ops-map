# SEO — Technical Best Practices

## Meta Tags

- Unique <title> per page (50-60 chars)
- Unique <meta name="description"> (120-155 chars)
- Canonical URL on every page
- Language: <html lang="xx">

## Open Graph

- og:title, og:description, og:image on all pages
- og:image: 1200x630px minimum
- twitter:card: summary_large_image

## Structure

- Single <h1> per page, strict heading hierarchy
- Breadcrumbs with structured data (BreadcrumbList)
- Internal linking: descriptive anchor text, no "click here"

## Technical

- Sitemap.xml generated and submitted
- robots.txt configured correctly
- 301 redirects for moved content (not 302)
- No orphan pages (every page reachable from navigation)

## Performance (SEO Impact)

- LCP < 2.5s, CLS < 0.1
- Mobile-friendly (responsive, touch targets > 48px)
- Core Web Vitals passing in PageSpeed Insights
